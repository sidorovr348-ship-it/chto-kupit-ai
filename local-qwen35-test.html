Тест локального ИИ на iPhone

Отдельный эксперимент. Модель Qwen3.5 0.8B будет работать в Safari через WebGPU. Вопросы обрабатываются на устройстве — они не отправляются на сервер приложения «Эй».

Перед запуском — прочитай

Первая загрузка модели — примерно 447 МБ по данным хранилища модели. Дополнительно загрузится программный модуль WebLLM. Для работы модели браузеру потребуется около 1,63 ГБ видеопамяти по оценке каталога; фактический расход может быть выше.

Рекомендую Wi‑Fi. На мобильном интернете лучше пока не запускать. Нажатие кнопки ниже явно разрешает загрузку. Модель загружается с Hugging Face, библиотека — с esm.run. Вопросы остаются в браузере.

Это небольшая экспериментальная модель, качество ответов ограничено. Не закрывай вкладку во время загрузки и теста. Если Safari перезагрузит страницу или выдаст ошибку, пришли её текст.
