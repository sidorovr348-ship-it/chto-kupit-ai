# КОНТРОЛЬНОЕ СОХРАНЕНИЕ — My AI Unified

Дата: 15.09.2026

## Главная цель
Сделать реально рабочее мобильное приложение My AI Unified для iPhone + Android и затем опубликовать его в App Store и Google Play.

Приложение должно уметь: чат, веб-поиск, поиск товаров в российских магазинах, фото и распознавание, камера, видео, документы, ZIP-архивы, голосовой ввод/ответ, озвучку и генерацию изображений.

Alice — только голосовой интерфейс/шлюз, а не отдельный ИИ.

## Самая последняя проблема
На iPhone текстовый чат отвечает, но голосовая кнопка не реагирует.
Требуемое поведение: один тап → запись → пауза → автоматическая остановка → распознавание → автоматическая отправка текста. Второй тап для остановки не нужен.

Последние изменения ещё нельзя считать полностью проверенными, пока не подтверждена цепочка:
GitHub → production-деплой → живая страница → реальный голос на iPhone.
Не говорить пользователю «полностью готово» без такой проверки.

## Нерешённые проблемы
- /photo периодически даёт HTTP 502; причина не установлена окончательно.
- Поиск/товары: ошибка разбора цены WB (например 595 ₽ превращалась в 1), иногда попадают неправильные дешёвые аксессуары.
- TTS (озвучка) нужно сделать более живым человеческим голосом, а не механическим.
- Иногда интерфейс пишет «Не удаётся связаться с AI-сервером»; прямую проверку API из текущего окружения ограничивает DNS, поэтому это не считать доказательством падения сервера.

## Голосовой сервер
В local-gateway.js есть POST /transcribe.
Модели/настройки:
- GROQ_TEXT_MODEL=openai/gpt-oss-120b
- GROQ_VISION_MODEL по умолчанию qwen/qwen3.6-27b
- STT_MODEL=whisper-large-v3-turbo
Ранее provider-файлы переводились на qwen/qwen3.8-27b для зрения.

## Правила работы с пользователем
- Пользователь не знает английский: любой английский технический термин в инструкции сопровождать переводом.
- Не заставлять пользователя вручную редактировать код на iPhone.
- Не ходить по кругу.
- Не просить повторно данные, которые уже есть.
- «Готово» только после фактической проверки.
- Отвечать коротко и прямо.
- Пользователь хочет контрольное сохранение примерно каждые 5 ответов.

## Следующий приоритет
Сначала фактически проверить последний production-деплой и голосовую цепочку. Если голос не работает — исправить, задеплоить и проверить снова. Только после этого переходить к фото 502 и остальным функциям.
